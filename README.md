# Своя игра

Викторина для компании от 2 до 8 человек: табло на большом экране, кнопки на телефонах, пульт ведущего с ответами.

## Как играть

1. **Экран игры** — открой сайт на ноутбуке или телевизоре → «Создать игру». Появится код комнаты и QR-код.
2. **Игроки** — сайт → «Я игрок» → код (или сканируют QR). Нажимать можно касанием, тряской телефона или кнопкой на наушниках.
3. **Ведущий** — сайт → «Я ведущий» → код и PIN из карточки «Ведущий». На пульте видны ответы, табло, кнопки «Верно/Неверно» и счёт.

Вопросы, картинки, звуки и модификаторы редактируются в «Редакторе вопросов» на экране игры. Пакет можно экспортировать в файл и импортировать на другом компьютере.

## Запуск у себя

Нужен [Node.js](https://nodejs.org) 18+. Зависимостей нет.

```
node server.js
```

Открой http://localhost:3000. Телефоны в той же Wi-Fi сети подключаются по QR-коду с экрана. Или просто запусти `start.bat` на Windows.

## Сайт в интернете (Render)

Репозиторий готов к бесплатному хостингу на [Render](https://render.com): New → Web Service → выбрать этот репозиторий. Настройки возьмутся из `render.yaml` (старт — `node server.js`). Каждый `git push` обновляет сайт.
